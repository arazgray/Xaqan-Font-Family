# Xaqan-Font-Family
A Azerbaijani (azb) Font Family, Originally made by **Saber Rastikerdar**

- خاقان (چالیشمادا) (وزیر اۆزرینده)

- خاقان قارانقوش (Regular آغؽرلیغی‌نین 0.1 یازؽمی حاضیر - دئنه‌مه سۆرجینده)
